# SubSync · 外挂字幕同步

订阅 MoviePilot 的 `TransferComplete` 事件，在整理完成的那一刻，把下载目录里的外挂字幕
按 strm **同名复制**到最终媒体库目录。

## 为什么需要它

用 strm 媒体库 + Alist/rclone 网盘挂载时，字幕文件留在下载目录，媒体库里没有字幕，
播放器刮削时就匹配不到。这里在整理完成的瞬间补齐这一步。

## 特性

- **零配置自动匹配**：先问 MoviePilot 自己的**转移历史**。MP 整理时已经把
  「原始资源名 → 整理后的中文名」记在了 `transferhistory` 表里，字幕按原始资源名
  查表即可直接落到最终位置，不用手写别名。
- **双通道**：事件驱动（整理完成立刻处理）+ 定时全库补扫（`/subsync_scan_all`
  或每天 04:30），补齐历史积压，不受事件触发时机影响。
- **强匹配才动手**：没有任何明确证据就整条放弃，宁可漏放也不放错。
- **自动向下兼容**：读不到转移历史（MP 版本差异）时静默退回启发式匹配，
  行为与旧版一致，不会报错也不会什么都不做。
- **幂等**：目标已存在且未开启覆盖时跳过，重复扫描不会反复复制。
- **纯标准库**：只依赖 Python 标准库和 MoviePilot 宿主，无需安装任何第三方包。

## 配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | 开 | 关闭后事件触发直接返回 |
| 仅同步中文字幕 | 开 | 关闭则同步所有语言；开启时对 `.srt` 抽样读文件头判断是否中文，非 `.srt` 直接按中文处理 |
| 覆盖已存在的目标字幕 | 关 | 开启后每次扫描都覆盖 |
| 复制后删除源字幕 | **关** | ⚠️ 不可逆。源字幕会被移除且无法恢复，仅在确认字幕已正确入库后再开启 |
| 用转移历史自动匹配 | 开 | 关掉即完全退回纯启发式匹配（调试用） |
| 下载目录 · 电影 | `/media/downloads/电影,/media/待上传` | **一格可以写多个目录**，用英文/中文逗号、分号或换行隔开 |
| 下载目录 · 剧集 | `/media/downloads/电视剧,/media/待上传` | 同上 |
| 媒体库目录 · 电影 | `/media/电影` | 只在这里面找 strm |
| 媒体库目录 · 剧集 | `/media/电视剧` | 同上 |
| 全库补扫 crontab | `30 4 * * *` | cron 表达式，非法时自动回退到默认值 |
| 事件通道扫描窗口 · 天 | `1` | 整理完成后往回看几天内的字幕；补扫不受此限制 |
| 别名映射（兜底） | 空 | 只有前两级都对不上时才需要，见下 |

所有路径都填 **MoviePilot 容器内可见的路径**（不是 NAS 宿主机路径）。

### 为什么下载目录建议写两个

MP 整理时可能把字幕留在下载目录，也可能连同视频一起移进「待上传」目录。
两个都写上就不用猜——插件会同时扫描，字幕落在哪边都能捡到。

## 匹配逻辑

按优先级依次尝试，任何一级拿到明确证据就停：

### ① 转移历史对照表（零猜测）

读 MP 的转移历史表，用字幕名去匹配记录里的**原始资源名**：

- 摘掉 `.chs` 之类的语言尾巴
- 剥掉分辨率、来源、编码、音轨、发布组、年份、季集号，得到「作品名核心」
- 核心词覆盖率 ≥ 80%（且至少命中 2 个词）即视为同一部作品
- 年份两侧都知道却不一致的直接排除，解决同名翻拍
- 命中后按「整理后的文件名」或「标题 + 年份 + 季集」落到媒体库里的具体 strm

字幕叫 `Avengers.Infinity.War.2018.2160p.WEB-DL.chs.srt`、
记录里的原始名是 `Avengers Infinity War 2018 UHD BluRay REMUX 2160p ...`，
两边核心名都收敛到 `avengers infinity war`，于是直接落成
`复仇者联盟3：无限战争 (2018) - 2160p.zh-Hans.srt`。

### ② 启发式匹配（无转移历史时的兜底）

1. 先判断字幕是否带季集号（`SxxExx`）——有则走剧集路径，否则走电影路径。
2. 从目标目录里的 strm 建立候选索引。
3. 打分规则：
   - 中文标题：算**双向最长公共子串**，连续 2 字以上才算命中
   - 英文标题：先剥离噪声，再做整词包含匹配
   - 别名命中额外加分
   - 文件名年份与目录年份一致时加分
4. 取分数最高者；**没有任何强匹配证据就整条放弃**。

### ③ 别名映射（最后兜底）

```
from|梦魇绝镇|迷离小镇
```

每行第一个字段是英文别名（按空格切成 token 匹配），后面是它可能对应的中文剧名。
只有在 ①② 都对不上时才需要填，绝大多数情况可以留空。

## 媒体库目录结构

两种写法都认，混着放也没问题：

```
电影/外语电影/F1：狂飙飞车 (2025)/F1：狂飙飞车 (2025) - 2160p.strm      ← 年份在目录名
电影/外语电影/复仇者联盟3：无限战争/复仇者联盟3：无限战争 (2018) - 2160p.strm  ← 年份在文件名
```

但位于 **115 中转 / 暂存目录**（路径里含 `115`、`downloads`、`staging`、`tmp` 等）
下面的 strm 一律不认——那还不是最终媒体库，字幕落进去会跟着中转文件一起丢掉。

## 剧集：严格按季集号定位

字幕带 `SxxExx` 就说明这是某一集的料，只在剧集里按季集号精确定位，
**不会因为剧集那条对不上就退到电影里去**——电影和剧集完全可能同名
（《沙丘》1984 电影 / 2024 剧集），那样会把整季字幕一起塞进电影目录。

- 字幕的 `SxxExx` 是权威集号，转移记录里的 `seasons` 只作为反向校验（对不上就放弃）
- 库里没有这一集 → 整条放弃，留给下一次补扫，不猜
- MP 的 `title` 字段偶尔为空，这时用 `dest` 所在目录名当剧名顶上

目标文件名规则：`<strm 文件名>.<语言标签>.<原扩展名>`，例如
`梦魇绝镇 - S01E08 - 第 8 集.zh-Hans.ass`。字幕永远落在对应 strm 所在的目录。

## 触发方式

- 在 MP 对话框发 `/subsync_scan_all` —— 立即全库补扫
- 定时服务 `SubSync.Backfill`，默认每天 04:30

## 已知边界

- 转移历史超过 20000 条时只取最近的一批；极老的字幕可能查不到，会退回启发式。
- `delete_source` 打开后源字幕会被 `unlink` 删除，属于不可逆操作。

## 离线验证

```bash
# 在 MoviePilot 容器内运行（需要能 import app.* 宿主包）
python tests/v3/subsync/verify_delete_source.py
```

覆盖 `delete_source` 的五种情形：开关关闭保留源文件、复制成功后删源、目标已存在跳过时不删、
覆盖后删源、复制失败时必须保留源文件。脚本使用临时目录，不触碰真实媒体目录。

若插件不在仓库默认位置，可用环境变量指定：

```bash
SUBSYNC_PLUGIN_PATH=/path/to/plugins.v3/subsync/__init__.py python tests/v3/subsync/verify_delete_source.py
```
