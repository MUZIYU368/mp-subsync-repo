# SubSync · 外挂字幕同步

订阅 MoviePilot 的 `TransferComplete` 事件，在整理完成的那一刻，把下载目录里的外挂字幕
按 strm **同名复制**到最终媒体库目录。

## 为什么需要它

用 strm 媒体库 + Alist/rclone 网盘挂载时，字幕文件留在下载目录，媒体库里没有字幕，
播放器刮削时就匹配不到。这里在整理完成的瞬间补齐这一步。

## 特性

- **事件驱动**：只处理本次整理涉及的源目录与目标目录，不做全盘扫描，比定时轮询快得多，
  也不会误伤无关文件。
- **强匹配才动手**：字面相近不算数，必须有明确证据才复制，避免字幕被丢进错误的剧集目录。
- **幂等**：目标已存在且未开启覆盖时跳过，重复整理不会反复复制。
- **纯标准库**：只依赖 Python 标准库和 MoviePilot 宿主，无需安装任何第三方包。

## 配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用插件 | 开 | 关闭后事件触发直接返回 |
| 仅同步中文字幕 | 开 | 关闭则同步所有语言；开启时对 `.srt` 抽样读文件头判断是否中文，非 `.srt` 直接按中文处理 |
| 覆盖已存在的目标字幕 | 关 | 开启后每次整理都覆盖 |
| 复制成功后删除下载目录的源字幕 | **关** | ⚠️ 不可逆。字幕会被移动到媒体库，下载目录中的原文件不再保留且无法自动恢复。仅在确认字幕已正确入库后再开启 |
| 下载目录（电影） | `/media/downloads/电影` | 填了之后，目录外的字幕一律不处理 |
| 下载目录（剧集） | `/media/downloads/电视剧` | 同上 |
| 别名映射 | 空 | 每行 `英文别名\|中文剧名A\|中文剧名B`，见下 |

### 别名映射

把英文资源名映射到中文库目录，解决「英文发布名 ↔ 中文剧名」对不上的问题：

```
from|梦魇绝镇|迷离小镇
```

每行第一个字段是英文别名（按空格切成 token 匹配），后面是它可能对应的中文剧名。
别名命中会获得高权重，能绕过整词匹配的失败。

## 匹配逻辑

1. 先判断字幕是否带季集号（`SxxExx`）——有则走剧集路径，否则走电影路径。
2. 从目标目录里的 `剧名 (年份)/Season N/*.strm` 建立候选索引。
3. 打分规则：
   - 中文标题：算**双向最长公共子串**，连续 2 字以上才算命中
   - 英文标题：先剥离分辨率 / 编码 / 发布组等噪声，再做整词包含匹配
   - 别名命中额外加分
   - 文件名年份与目录年份一致时加分
4. 取分数最高者；**没有任何强匹配证据就整条放弃**，不做猜测。

目标文件名规则：`<strm 文件名>.<语言标签>.<原扩展名>`，
例如 `梦魇绝镇 - S01E08.zh-Hans.ass`。

## 已知边界

- 只在整理完成那一刻处理本次涉及的目录。如果下载源目录已经被清理掉，插件会自动跳过，
  此时需要依赖 cron 版 `sync_subs_to_strm.py` 兜底。
- `delete_source` 打开后源字幕会被 `unlink` 删除，属于不可逆操作。

## 离线验证

```bash
# 在 MoviePilot 容器内运行（需要能 import app.* 宿主包）
python tests/v3/subsync/verify_delete_source.py
```

覆盖 `delete_source` 的五种情形：开关关闭保留源文件、复制成功后删源、目标已存在跳过时不删、
覆盖后删源、复制失败时必须保留源文件。脚本使用临时目录，不触碰真实媒体目录。

若插件不在仓库默认位置，可用环境变量指定：

```bash
SUBSYNC_PLUGIN_PATH=/path/to/plugins.v3/subsync/__init__.py python tests/v3/subsync/verify_delete_source.py
```
